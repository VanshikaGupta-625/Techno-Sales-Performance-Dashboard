
# Techno Sales Performance Dashboard

An interactive **Sales Performance Dashboard created in Tableau** using the Techno Sales practice dataset.

## 📊 Project Overview

This dashboard provides a clear overview of sales performance and helps analyze sales across different states, products, categories, and order statuses.

## 🛠️ Tools Used

* Tableau
* Microsoft Excel
* GitHub

## 📈 Dashboard Highlights

* Total Sales
* Total Profit
* Total Quantity
* State-wise Sales Analysis
* Sales by Category
* Sales by Product
* Sales by Order Status
* Monthly Sales Trend

## 🎯 Project Objective

The objective of this project is to transform raw sales data into an interactive and easy-to-understand dashboard that can help identify sales patterns and compare performance across different dimensions.
